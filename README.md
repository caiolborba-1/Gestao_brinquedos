Sistema de Gerenciamento de Estoque

Esse projeto é um sistema simples feito para organizar os itens de um estoque. Nele é possível cadastrar, ver, alterar e excluir produtos.

Foi desenvolvido usando PHP, MySQL e HTML, sendo necessário utilizar o XAMPP para rodar o sistema.

A tela principal mostra os itens cadastrados e possui um formulário para adicionar novos produtos. Também existem as opções de editar e excluir cada item quando necessário.
